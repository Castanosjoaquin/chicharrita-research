# Fuentes

Bibliografía consolidada de las cinco investigaciones. La fuente de verdad
estructurada es el `sources.json` de cada carpeta de `research/`; este archivo es
la vista unificada y legible, con el nivel de evidencia y el acceso de cada
fuente, y sirve para detectar en qué se apoyan varias investigaciones a la vez.

## Jerarquía de evidencia que usamos

De mayor a menor peso, según las reglas del proyecto:

1. Papers revisados por pares (*peer-reviewed*).
2. Preprints (bioRxiv, arXiv), marcados como tales.
3. Patentes y documentos regulatorios.
4. Notas técnicas institucionales (INTA, CONICET, EMBRAPA, universidades).
5. Prensa especializada.
6. Comunicación corporativa, que es evidencia de intención y no de eficacia.

Los marcadores de confianza son los de `CLAUDE.md`: `[E]` establecido, `[R]`
reportado, `[H]` hipótesis nuestra, `[?]` incierto o en conflicto. Cuando dos
fuentes se contradicen se reportan las dos y se marca `[?]`: no se promedia ni se
elige la más cómoda.

Ninguna fuente entra a este archivo si no se abrió. Las que se buscaron y no se
pudieron abrir van a `PREGUNTAS_ABIERTAS.md`, no acá.

---

## Índice consolidado

Se puebla en la integración, con una fila por fuente: identificador, cita,
tipo, nivel de evidencia, acceso, y en qué investigaciones se usó. Las fuentes
citadas por más de una investigación se marcan, porque son el núcleo
bibliográfico del proyecto y lo primero que conviene leer entero.
