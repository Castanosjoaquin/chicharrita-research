# research — índice

La investigación está organizada en dos tandas. Las **R** son los relevamientos
de fondo, hechos antes de recibir el material oficial del Investigathón: sirven
para entender el dominio y decidir dónde competir. Las **olas** son el trabajo
posterior, cada una disparada por un hito concreto —el material oficial, un
checkpoint, la respuesta de un mentor— y cada una produce resultados medidos.

Cada carpeta tiene su `REPORT.md`, y las que hicieron cómputo guardan los
comandos exactos en `datos/COMANDOS.md` o `scripts/`.

## Relevamientos de fondo

| Carpeta | Qué pregunta contesta |
| --- | --- |
| [`R1_fundamentos`](R1_fundamentos/) | Cómo funciona el RNAi y cómo funciona el sistema chicharrita–achaparramiento–maíz. La base para discutir de igual a igual con un biólogo molecular. |
| [`R2_attention_diseno_arn`](R2_attention_diseno_arn/) | ¿Sirve tratar al ARN como tokens de un modelo de lenguaje y diseñar con *attention*? Evaluación de una idea propia. |
| [`R3_apolo_biotech`](R3_apolo_biotech/) | Qué hace ya la industria. Inteligencia competitiva sobre APOLO Biotech, con fuentes abiertas únicamente. |
| [`R4_frontier_ml_rna`](R4_frontier_ml_rna/) | Estado del arte en aprendizaje automático aplicado a biotecnología de ARN, para elegir subcampo. |
| [`R5_metodologias_ejes`](R5_metodologias_ejes/) | Cómo se trabaja de verdad en cada uno de los tres ejes en los que competimos, y cómo se reparte entre cuatro personas. |
| [`R6_estrategias_molicutes`](R6_estrategias_molicutes/) | Qué se puede hacer contra los mollicutes del achaparramiento sin dirigir el RNAi al patógeno. |
| [`R7_microgravedad`](R7_microgravedad/) | Estructuras de proteínas y ARN en microgravedad: qué hay y si sirve de algo acá. Cinco pistas. |
